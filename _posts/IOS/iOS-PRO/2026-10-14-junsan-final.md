## 암기 숫자·공식

- **실행시간 = 명령어 수 × CPI ÷ 클록주파수** (지수끼리 따로: G=10⁹, ms=10⁻³, μs=10⁻⁶, ns=10⁻⁹)
- **캐시 평균 접근시간 = h×캐시 + (1−h)×주기억** (20ns/150ns/80% → 46ns)
- **파이프라인 = (K + N − 1) × T** (4단계 10개 → 13T)
- **암달 = 1 / [(1−p) + p/s]** (50%를 2배 → 1.33배, s=∞여도 2배 못 넘음)
- **IEEE754 단정도 = 부호1 + 지수8(Bias 127) + 가수23** / 배정도 1+11(1023)+52
- **n개 구분 비트 수 = 2ᵏ ≥ n인 최소 k** (20개 → 5비트, 레지스터 16개 3-주소 → 4×3=12비트)
- 2진 소수 자리값 0.5 / 0.25 / 0.125 / 0.0625 → 0.625 = .101
- 264₍₈₎ = 2×64+6×8+4 = **180**
- 2의 보수 음수 읽기: 다시 2의 보수 취하고 −. 1111…1 = **−1**, 1000…0 = 최소 음수
- 해밍: 패리티는 1,2,4,8 자리 / **오류 위치 = 틀린 패리티 번호의 합** / 16비트면 패리티 5개

# PART 3. 네트워크

## 숫자·공식

- **BPS = Baud × 비트/신호** (4위상 디비트 2, 8위상 트리비트 3, 16위상 4). full word = 32비트
- **샤논 C = W log₂(1 + S/N)**
- **나이퀴스트: 최고 주파수 2배 표본화** (4kHz → 8000회)
- **망형 회선 = n(n−1)/2**, 포트 = n−1
- **서브넷 수 = 2^빌린비트, 호스트 = 2^남은비트 − 2**. /26 → 4개·62대, /27 30대, /28 14대, /30 2대
- MAC 48비트 / IPv4 32비트 / **IPv6 128비트, 16진수 8개, 헤더 고정 40B, IPsec 기본, 브로드캐스트 없음(애니캐스트)**
- RIP 최대 홉 **15**
- 클래스: A 0~127(/8) / B 128~191(/16) / C 192~223(/24) / **D 224~239 멀티캐스트** / E 240~
- 사설 IP: 10.x / 172.16~31 / 192.168. 루프백 127.0.0.1. 호스트부 전부 0=네트워크, 전부 1=브로드캐스트

## 공식·계산

- **빅오 순서: O(1) < log n < n < n log n < n² < 2ⁿ < n!**
- 2차원 배열 **행 우선: 시작 + (i×열수 + j)×크기** (C) / 열 우선 (j×행수 + i) (Fortran). A[3][4], 1000, A[2][1] → 1036
- **`*(p+2)` = a[2] / `*p+2` = a[0]+2** ⚠️ / p++ 후 p[0]=a[1]
- 연결리스트 삽입: `new->next = p->next; p->next = new;` **순서 바꾸면 끊김**
- 원형 큐: rear=(rear+1)%N, **포화 (rear+1)%N==front**, 최대 N−1개
- 이진 트리: 레벨 i 최대 2^(i−1) / 깊이 k 최대 2^k − 1 / **단말 n₀ = n₂ + 1**
- 완전 그래프 간선: **무방향 n(n−1)/2, 방향 n(n−1)**. 신장 트리 간선 = n−1
- 힙 배열(1부터): 자식 2i, 2i+1 / 부모 i/2
- B-트리 m차: 최대 자식 m, 최대 키 m−1, 최소 자식 ⌈m/2⌉, 단말 같은 레벨. 분할 시 가운데 키 부모로
- 해싱 선형조사: 크기 7, 10·17·24 → 3, 4, 5

|---|---|
| 선형/비선형 | 선형: 배열·리스트·**스택·큐·데크** / 비선형: **트리·그래프** |

| 해시 | 제산법(소수로 나눈 나머지, 최다) / 제곱법 중간자리 / 폴딩. 충돌: 개방주소(선형·이차·이중) / **체이닝**(연결리스트) |

## 정렬 (반드시)

| 정렬 | 평균 | 최악 | 안정 | 메모 |
|---|---|---|---|---|
| 버블·선택·삽입 | n² | n² | 버블·삽입 O, 선택 X | **삽입 최선 O(n)**(정렬된 입력), 선택은 항상 n² |

## ① 전세대출 보증 규제 ⭐⭐⭐ (가장 유력, SGI 본업)

- **배경**: 전세대출이 갭투자 자금줄 → 집값 상승 / 전세사기 / 가계부채
- **내용**: 보증비율 축소, 1주택자 한도 제한, 전세대출 이자 DSR 반영, **비거주 1주택자 보증 제한**
- **영향**: 임대차 → **반전세·월세화**, 세입자 주거비↑, 전세 매물↓로 전세가 오히려↑ / 부동산 → 갭투자↓ / 보증기관 → 보험료 수입↓ but 투기수요 빠져 **손해율 개선**
